### 這是用於自我提升的小型專案:
1. 目的: 讓使用者輸入自身的時間排成，並可視覺化一天、一周、一月份的任務進度安排
2. 學習目標: 程式開發與創建、資料模型搭建、軟體架構、操作者使用流程圖、OLTP & OLAP
4. 目前主要使用本地端創建: python+flask+mysql
